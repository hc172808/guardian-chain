---
name: Stablecoin approval
description: Product rule for reviewing user-created stablecoins before deployment.
---

Every stablecoin submission—including one created by an admin or founder—must remain pending until an admin/founder explicitly approves it. Notify all admin/founder reviewers in-app and link the notification to the stablecoin approval queue. Approval submits the on-chain token deployment.

**Why:** the user asked that admins/founders receive a notification, open the approval page, and click an approval button for each created stablecoin.

**How to apply:** preserve the review gate for all creator roles; never auto-deploy a privileged creator's submission or treat notification delivery as optional.
